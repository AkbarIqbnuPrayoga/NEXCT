# 💼 Web Portofolio – NEXCT

Website ini adalah **web portofolio pribadi** yang berisi kumpulan project, sertifikat, dan karya digital yang telah saya kerjakan selama proses belajar dan pengembangan diri di bidang teknologi.

## 📌 Tentang Website

Portofolio ini dibuat sebagai media dokumentasi dan showcase kemampuan, khususnya dalam:
- Pengembangan web
- Pemanfaatan teknologi berbasis sistem
- Pembuatan tools digital berbasis web

Website ini bersifat **static site**, ringan, dan mudah diakses.

---

## 🚀 Isi Website

### 🔹 Project Web
Beberapa project yang ditampilkan dalam website ini antara lain:
- **Image to Prompt Web**  
  Mengubah gambar menjadi prompt teks untuk kebutuhan AI atau deskripsi visual.
- **Music Web Player**  
  Website pemutar musik online yang dapat diakses langsung melalui browser.
- **URL Shortener Web**  
  Website untuk memendekkan link agar lebih ringkas dan mudah dibagikan.

### 🔹 Sertifikat
Website ini juga menampilkan **sertifikat pelatihan dan pencapaian** sebagai bukti keikutsertaan dalam berbagai kegiatan pembelajaran dan pengembangan skill.

---

## 🛠️ Teknologi yang Digunakan

- HTML

- JavaScript
